---
title: "3. Multi-Agent: Specialists"
description: "One agent becomes four — a lead that delegates, and three specialists with their own narrow tool access."
---

The single `marketing-agent` from [steps 1–2](/examples/marketing-agent/advanced) already does everything asked of it, but it does all of it with the same tools and the same system prompt, whether it's drafting copy or checking a competitor. Splitting into specialists means each one has a system prompt written for exactly one job, and can't call tools outside that job — see [Agent Types § Building Blocks](/getting-started/agent-types) for the full mechanics behind `allowedTools`/`delegatesTo` before this page; it only covers what's specific to this example.

## A third tool, for the new specialist

```ts src/tools/scheduling.ts
import { defineTool, z } from '@backendkit-labs/agent-core';

export const schedulePost = defineTool({
  name: 'schedule_post',
  description: 'Schedules a drafted post for publishing at a given time',
  input: z.object({
    content: z.string(),
    platform: z.enum(['twitter', 'linkedin', 'instagram']),
    publishAt: z.string().describe('ISO 8601 timestamp'),
  }),
  execute: async ({ platform, publishAt }) => {
    // TODO: call your scheduling backend
    return `Scheduled on ${platform} for ${publishAt}.`;
  },
});
```

## Four profiles, one roster

```ts src/agents.ts
import type { AgentProfile } from '@backendkit-labs/agent-core';

export const marketingLead: AgentProfile = {
  id: 'marketing-lead',
  name: 'Marketing Lead',
  icon: '📣',
  description: 'Coordinates campaign requests across specialists',
  systemPrompt: `Your job is to understand the request and delegate via ask_agent —
never draft copy, research competitors, or schedule anything yourself.
- Copy or captions → copywriter
- Competitor or market research → seo-analyst
- Publishing/timing → scheduler`,
  allowedTools: [],
  delegatesTo: ['copywriter', 'seo-analyst', 'scheduler'],
};

export const copywriter: AgentProfile = {
  id: 'copywriter',
  name: 'Copywriter',
  icon: '✍️',
  description: 'Drafts social copy in the house voice',
  systemPrompt: 'You write social media copy. Nothing else is your job.',
  allowedTools: ['draft_social_post'],
  delegatesTo: [],
};

export const seoAnalyst: AgentProfile = {
  id: 'seo-analyst',
  name: 'SEO Analyst',
  icon: '🔍',
  description: 'Researches competitor campaigns and keyword opportunities',
  systemPrompt: 'You research competitors and market positioning. You do not write copy.',
  allowedTools: ['competitor_lookup'],
  delegatesTo: [],

  id: 'scheduler',
  name: 'Scheduler',
  icon: '🗓️',
  description: 'Schedules approved posts for publishing',
  systemPrompt: 'You schedule already-approved content. You do not draft or research.',

  delegatesTo: [],
};
```

## Wiring the roster

```ts src/engine.ts {1,10-16}
import { createBaseEngine, StdoutTransport } from '@backendkit-labs/agent-core';
import type { LLMProvider, Transport } from '@backendkit-labs/agent-core';
import { marketingLead, copywriter, seoAnalyst, scheduler } from './agents';
import { draftSocialPost, competitorLookup } from './tools/content';
import { schedulePost } from './tools/scheduling';
import { memory } from './memory';
import { brandVoiceSkill, platformLimitsSkill } from './skills/brand-voice';

const anthropicProvider: LLMProvider = { /* ...same as step 1 */ };

export function createEngine(transport: Transport = new StdoutTransport()) {
  return createBaseEngine({
    agents: [marketingLead, copywriter, seoAnalyst, scheduler],
    tools: [draftSocialPost, competitorLookup, schedulePost],
    skills: [brandVoiceSkill, platformLimitsSkill],
    memorySystem: memory,
    providers: { anthropic: anthropicProvider },
    defaultProvider: 'anthropic',
    defaultAgent: 'marketing-lead',   // ← only this one gets ask_agent + the roster listing
    transport,
  });
}
```

Three things worth being explicit about, all verified against `AgentEngine.ts` (see [Agent Types](/getting-started/agent-types) and [Skills § In a multi-agent roster](/concepts/skills#in-a-multi-agent-roster-shared-by-default-not-per-agent) for the source citations):

<Warning>
  - `ask_agent` is only auto-injected into `marketing-lead` because it's `defaultAgent`. `copywriter`/`seo-analyst`/`scheduler` structurally cannot delegate further, regardless of what their own `delegatesTo` says (they're `[]` here, correctly).
  - `skills` and `memorySystem` are still engine-wide, not per-specialist — `brand-voice` and `platform-limits` fire for whichever agent ends up handling a turn, lead or specialist alike, and all four share the same campaign/brand-fact/pattern memory.
  - `marketingLead`'s `allowedTools: []` is deliberate, not an oversight — its system prompt already tells it never to answer directly, and having zero tools besides the auto-injected `ask_agent` makes that structurally true, not just a suggestion.
</Warning>
