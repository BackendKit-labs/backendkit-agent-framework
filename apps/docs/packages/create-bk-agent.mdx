```bash
npx create-bk-agent my-project
```

See [Quickstart](/getting-started/quickstart) for the prompt walkthrough and [Agent Types](/getting-started/agent-types) for what each choice actually generates, file by file. This page is about the tool itself.

## How it assembles a project

Two layers, composed:

- **`base/{architecture}`** — the skeleton. `coding`, `autonomous`, and `minimal` are self-contained; `multi-agent`, `single`, and `enterprise` are meant to be layered with a deploy mode.
- **`deploy/{mode}`** — overlaid on top, for `repl`, `mcp-http`, `mcp-stdio`, `hybrid`, and `web`. It patches `package.json` scripts and, for MCP modes, adds `@backendkit-labs/mcp-server` as a dependency and writes the [`AgentMCPServer`](/packages/mcp-server) wrapper. A sixth deploy mode, `library`, is a deliberate no-op — pick it and no overlay gets copied at all, leaving the bare base template with no entry point, meant to be imported programmatically rather than run standalone.

`orchestrator` architecture doesn't use the deploy-overlay system at all — it has its own four self-contained variants (`blank`/`ventas`/`marketing`/`soporte`), each a complete `orchestrator.yaml` + flows + vault.

## What gets patched after copying

- **`.env`** generated from `.env.example` with the right variable name for your chosen provider (`ANTHROPIC_API_KEY`, `OPENAI_API_KEY`, `LLM_API_KEY` for DeepSeek, `OLLAMA_BASE_URL`) — except `enterprise`, which injects `VAULT_PATH` into its own `.env.example` instead.
- **Skill pack hints** — picking Node/Python/Go/Docker skill packs appends a marked comment block to `src/engine.ts` pointing at where to wire real skill activation; it doesn't inject full skill YAML (`create-bk-agent add skills` handles that separately).
- **`package.json` name** — set to your project name; `deployMode`-specific scripts (`dev`/`start`/`server`) added or removed depending on what you picked.

<Warning>
  `packages/templates/` also has top-level `autonomous/`, `coding/`, `minimal/`, and `domain-agent/` directories outside `base/`. `scaffold.ts` only ever reads from `base/` — those are orphaned, diverged copies, not alternate outputs. If you're editing a template to change what gets generated, `base/` is the one that matters.
</Warning>
