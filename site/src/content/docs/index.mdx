## One governed call

<Tabs>
  <TabItem label="Tool">

```ts
import { defineTool, z } from '@backendkit-labs/agent-core';

export const pay = defineTool({
  name: 'pay_invoice',
  description: 'Pay an invoice',
  destructive: true,                       // cannot be undone: the engine will ask
  input: z.object({ invoiceId: z.string(), amount: z.number() }),
  execute: async ({ invoiceId }) => `paid ${invoiceId}`,
});
```

  </TabItem>
  <TabItem label="Policy">

```ts
import type { ToolPolicy } from '@backendkit-labs/agent-core';

export const rules: ToolPolicy = {
  decide(_principal, call) {
    if (call.tool.name === 'pay_invoice' && (call.args.amount as number) > 10_000) {
      return { effect: 'ask', reason: 'payment above 10k', accepts: ['human'] };
    }
    return { effect: 'allow' };
  },
};
```

  </TabItem>
  <TabItem label="Engine">

```ts
const engine = createBaseEngine({
  providers: { main: provider }, defaultProvider: 'main',
  agents: [treasurer], defaultAgent: 'treasurer', tools: [pay],
  transport, workingDir: process.cwd(),
  policy: rules,                                       // who may do what
  approvals: new FileApprovalStore('./approvals'),     // asks wait for a person, even across processes
  audit: new HashChainAuditSink('./audit.log'),        // one tamper-evident record per call
});
```

  </TabItem>
</Tabs>

## What you can build

| Kind of agent | What it is | Start from |
|---|---|---|
| [Assistants](/agents/assistants/) | Chat with a few typed tools | `agent-core` |
| [Coding agents](/agents/coding/) | Ten specialists that read, edit and run code | `agent-coding` |
| [Teams of agents](/concepts/multi-agent/) | Specialists and routing between them | `agent-core` |
| [Autonomous agents](/agents/autonomous/) | Cron, webhook and event triggers, unattended | `agent-core`, `agent-web` |
| [Knowledge agents](/agents/knowledge/) | Support, HR, sales, finance and ops over your documents | `agent-enterprise` |
| [Agents as services](/agents/services/) | Served to a browser, over MCP, or to other agents | `agent-web`, `mcp-server`, `agent-protocol` |
| [Agents that run code](/agents/sandboxed/) | Commands confined by a policy that fails closed | `agent-sandbox` |
| [Agents that connect](/agents/connected/) | HubSpot, Jira, calendars, documents, payments | `mcp-connectors`, `document-extract`, `aval-tools` |
| [Durable flows](/concepts/flows/) | Business processes that survive a crash and wait for a person | `agent-core`, `agent-flow-queue` |

[All kinds of agents, and how to choose](/agents/overview/).

## The packages

| Package | Use it for |
|---|---|
| [`agent-core`](/packages/core/) | The engine, tools, governance, flows, memory, MCP. Everything starts here. |
| [`agent-providers`](/packages/providers/) | The model: OpenAI-compatible APIs (OpenAI, DeepSeek, Ollama) and Anthropic. |
| [`agent-testkit`](/packages/testkit/) | A scripted provider, a mock transport and a mock LLM server. |
| [`agent-flow-queue`](/packages/flow-queue/) | Flows across processes: steps on BullMQ workers, runs in Redis. |
| [`agent-sandbox`](/packages/sandbox/) | Confining what agents run. |
| [`mcp-server`](/packages/mcp-server/), [`agent-protocol`](/packages/agent-protocol/), [`agent-web`](/packages/web/) | Serving agents to other programs and to browsers. |
| [`create-bk-agent`](/packages/create-bk-agent/) | The project scaffolder. |
